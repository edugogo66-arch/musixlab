# MusixLab

Comprender la música a través de la interacción.

Portal de acceso a [Fifther](https://edugogo66-arch.github.io/fifther/) y [FretTrainer](https://edugogo66-arch.github.io/frettrainer/). PWA independiente.

Publicar todos los archivos en la raíz del repositorio `musixlab` mediante GitHub Pages. Para actualizar el portal, editar index.html y cambiar la versión de caché en sw.js.
