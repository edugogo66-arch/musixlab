# MusixLab

Comprender la música a través de la interacción.

Portal de acceso a Fifther y FretTrainer. PWA independiente.

Publicar todos los archivos en la raíz del repositorio `musixlab` mediante GitHub Pages. Los enlaces a FretTrainer usan el nombre supuesto `frettrainer`; confirmar en Settings → Pages del repositorio correspondiente. El icono de FretTrainer es provisional. Para actualizar el portal, editar index.html y cambiar la versión de caché en sw.js.
